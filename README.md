# Automated Software Testing & Performance Analysis

A test automation project demonstrating unit testing, UI automation, performance testing and CI/CD integration.

## Tools & Technologies

- Java
- JUnit 5
- Cypress
- JMeter
- Maven
- Git & GitHub
- GitHub Actions

## Testing Activities


### Cypress
- Created end-to-end UI tests.
- Validated user inputs and form validation.
- Verified UI behavior and user interactions.

### JMeter
- Created load testing scenarios.
- Simulated multiple users accessing the application.
- Analyzed response times and failed requests.

### JUnit
- Created unit tests to validate application functionality.
- Used Maven to build and execute automated tests.

### CI/CD
- Configured GitHub Actions to automatically run tests.
- Automated test execution on code pushes.
- Used CI/CD feedback to identify test failures early.
